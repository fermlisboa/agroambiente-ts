# Dev Container for Vite + React + TypeScript

This container uses Node.js 20 and comes with Prettier, ESLint, and Tailwind CSS extensions for VS Code.

## Como usar
1. Certifique-se de ter o Docker instalado.
2. Abra o projeto no VS Code.
3. Quando solicitado, clique em "Reabrir em Container" ou use o comando "Dev Containers: Reopen in Container".
4. O ambiente já terá Node 20 e todas as dependências instaladas.

---

- Node.js 20
- npm install automático
- Extensões recomendadas: Prettier, ESLint, Tailwind CSS
